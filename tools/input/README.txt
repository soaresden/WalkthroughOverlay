Optional "batch" mode for the command line:  python guide2switch.py --cli

  input/<Guide name>/*.pdf *.png *.txt   ->  guides_out/<Guide name>/...
  loose files here                       ->  guides_out/Misc/...

For everyday use, double-click guide2switch.bat instead: it opens the window
where you drop the files of one guide, name it, check the before/after preview
and convert.
